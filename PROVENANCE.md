# Provenance

## Project boundary

This repository was initialized during the Agents for Humans Hackathon submission period.

## Current policy

- New hackathon implementation is written in this repository.
- Standard open-source libraries and frameworks may be used according to their licenses.
- Prior professional/architectural experience may inform design decisions.
- Existing Anika application source code, customer code, customer data, credentials, and proprietary implementation are excluded.
- Any pre-existing non-standard work later incorporated must be recorded here before submission.

## Secrets

OAuth client secrets, refresh tokens, mailbox credentials, and production secrets remain outside this repository.

## Ownership / entrant

The earlier instruction here was to withhold the licence until ownership
was resolved. That instruction has been overtaken by events and this
section now records the actual position.

Observable facts, as of 2026-09-11:

- The repository is public at `github.com/MarketIQX/afh-crossborder-agent`,
  owned by the **MarketIQX** GitHub organisation.
- The **MIT** licence is committed as `LICENSE` and announced in the
  README and the repository's About section.
- The hackathon requires a public repository carrying an MIT or Apache
  licence, so publishing under MIT was a condition of entering at all.

Resolved on 2026-09-11 by the owner:

- The **entrant of record is an individual**, not a company.
- That same individual runs MarketIQX and controls the MarketIQX GitHub
  organisation, the AWS account used for this build, and the AWS Builder
  ID given in the submission. They are separate accounts under one
  person, not separate parties.
- The repository was created new for this hackathon, in line with the
  fresh-code rule, rather than reusing existing company repositories.

No third party holds rights in this work, and no employer, client or
collaborator contributed to it. The MIT licence therefore stands
correctly.

The licence was applied before this question was formally closed. That
sequence is recorded rather than tidied away, because a provenance file
that presents a clean order of events it did not follow is worth less
than one that admits the real order.
