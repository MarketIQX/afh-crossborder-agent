# Nicole architecture diagrams

## `nicole-live-architecture.svg`
Primary hackathon / Devpost architecture diagram. Status labels are deliberate:

- **BUILT** - implemented in the repository/product surface.
- **PROVEN** - exercised by deterministic or live boundary evidence.
- **DEPLOYED / AWS LIVE** - present in the current AWS deployment.
- **NEXT** - not yet complete and not claimed as implemented.

The successful live-case and repeated behavioral-acceptance gates remain `NEXT` until they are actually passed.

## `nicole-2031-vision.svg`
Long-term target architecture for Nicole as a governed multi-tenant professional intelligence platform. Boxes marked `2031 TARGET` are roadmap capabilities, not hackathon implementation claims.

The two-diagram split is intentional: the current diagram is the evidence claim; the 2031 diagram is the product thesis.
